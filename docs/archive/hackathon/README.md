# Hackathon-era documents (archived)

These files describe how SiteScribe was built during the NCSEA Hackathon 2026:
one owner per `sitescribe/` module, merges by RBB007 and the hackathon mergers,
and a Cloudflare quick-tunnel deployment. They are kept for history only.

- They are **not** current process. See the root [README](../../../README.md),
  [CONTRIBUTING.md](../../../CONTRIBUTING.md) and [AGENTS.md](../../../AGENTS.md).
- The tunnel URL and server paths in `DEPLOY.md` are retired. Production runs
  on Render (see [docs/operations.md](../../operations.md)).
- The `sitescribe/models.py` data-model notes in `AI_INSTRUCTIONS.md` and
  `INTEGRATION_PLAN.md` still help when reading `webapp/bridge.py` and
  `sitescribe/word_report.py`. Check them against the code before relying on them.
